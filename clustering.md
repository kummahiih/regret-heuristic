# ATC mapping on the probe

Particle = linear r head.
Edge = fork (copy parent weights into child) or step-in-place.
Cluster root = node whose subtree weight W(n) ≥ k and every child has W < k; k = max(2, 0.05 N).
C0 is boosted for the next SGD step (CDS pick).

This is genealogy clustering of readouts, not Vallivaara-style positioning (IPIN 2025). Monty Hall 2013 is cited only for the classic selection framing; no coauthor claim.

No Alias method / PF resample. Explicitly out of scope.

Clustering, not positioning.
